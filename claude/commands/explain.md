`$ARGUMENTS` について解説してください。

解説の構成:

1. **要点（3 行以内）**: 何のためのものか、どこで使われているか。
2. **動作の流れ**: 入力 → 処理 → 出力を、コード上の行を引用しながら（`path:line` 形式）。
3. **依存関係**: 呼び出し元・呼び出し先で重要なもの。
4. **注意点**: ハマりやすい点、副作用、暗黙の前提があれば。
5. **改善余地**: 明らかな問題があれば短く。なければ書かない。

ルール:

- 引用するコード片は最小限。長い貼り付けはしない。
- 自分の推測と、コードから読み取れる事実を区別する。
- 「分かりません」と言うべきところでは言う。
