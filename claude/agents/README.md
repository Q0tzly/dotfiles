# agents/

カスタムサブエージェント。`Agent` ツール経由で `subagent_type: <ファイル名>` として呼び出される。

## なぜサブエージェント

- 結果が膨大になる調査をメインのコンテキストに流し込まない（要約だけ返ってくる）。
- 独立した複数の調査を並列実行できる。
- 特定タスク用のシステムプロンプトとツール権限を固定できる。

## フォーマット

```markdown
---
name: my-agent
description: いつ・なぜこのエージェントを使うかを明確に。Claude が自動で選ぶ判断材料になる
tools: Read, Grep, Glob, Bash  # 任意。空欄なら全ツール
model: sonnet                  # 任意。haiku/sonnet/opus
---

ここがエージェントのシステムプロンプト。
役割・出力フォーマット・禁止事項を明確に書く。
```

## 追加するときの方針

- 「Explore で十分」「自分で grep すれば済む」タスクには作らない。
- `description` は呼び出し判断に直結する。トリガー条件を具体的に書く。
- ツールは絞る。書き換えが不要なら Read/Grep/Glob だけにする。
